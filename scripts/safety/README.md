# Safety and Publication Gates

- `scan_public_artifacts.sh` — scan for prohibited or suspicious public artifacts
- `validate_public_repo.sh` — run repository-level public validation
- `verify_private_evidence_manifest.sh` — verify a private evidence manifest
- `check_markdown_links.py` — validate local Markdown targets and heading fragments

These gates supplement human review; they do not make raw evidence safe to
publish automatically.
