
# Native Loader Public Research Utilities

- `verify_public_manifest.py` — verifies the sanitized repository manifest.
- `summarize_runtime_status.py` — validates and summarizes the public JSON status.
- `check_publication.py` — fail-closed privacy/content gate.
- `frida/` — generic original Frida 17 loader-observation infrastructure.

These tools process public/sanitized data only. Private evidence archives are
not required and must not be copied into the repository.
