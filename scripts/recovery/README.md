# Recovery Utilities

- `audit_recover_14a_r2_evidence.py` — audit/recover Test 14A-r2 evidence
- `recover_14b_d1_media.py` — recover Test 14B disconnected media
- `finalize_14b_disconnected_d1.py` — finalize the recovered Test 14B baseline

These utilities are bounded evidence-recovery tools, not general device
recovery or firmware-modification scripts.
