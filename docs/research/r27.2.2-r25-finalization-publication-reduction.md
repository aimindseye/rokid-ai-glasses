# R27.2.2 — r25 finalization/publication implementation reduction

R27.2.1 proved independent canonical equivalence for seven r25 private-evidence finalizers and six sanitized-publication verifiers.

R27.2.2 preserves the original 13 implementations by exact SHA-256 before mutation, then retains each historical filename as a thin compatibility shim:

- finalizer shims delegate to `scripts/research/canonical/r25_finalizer.py`;
- publication-verifier shims delegate to `scripts/research/canonical/r25_publication_verifier.py`;
- existing runner and synthetic-test call paths remain valid;
- no historical path is deleted;
- no device, network, or privileged operation is performed.

The retirement verifier compares the archived originals with the live shims using the same synthetic contracts established by R27.2.1. Finalizers are compared on stdout, manifest bytes, ZIP members/content, ZIP metadata, sidecars, and required-file rejection. Publication verifiers are compared on successful stdout plus privacy and semantic rejection behavior.

After acceptance, the active implementation count for this family is one canonical finalizer engine plus one canonical publication-verifier engine; the 13 historical entry points are compatibility shims only.
