# R27.1.3 — Canonical Source-Contract Framework

## Purpose

Provide a stable semantic entry point for revision-specific source-contract checks while preserving the historical implementations and their exact source identities.

## Census correction

The current tree contains 32 files matching `scripts/tests/check_*_source_contract.py`:

- 29 Test 21 source-contract checkers;
- 3 Test 20 source-contract checkers.

The earlier lineage estimate of 31 was a family-level approximation rather than the exact current file count.

## Applicable migration set

All 29 Test 21 checkers pass against the current repository source tree and are represented by canonical profiles.

The three Test 20 checkers remain historical/deferred in this stage. They are intentionally not counted as canonical equivalence passes because their source contracts describe different snapshots of the Test 20 app; for example, the r3.2.1 checker expects a superseded app-version marker, while the r3.3 checker requires an output report argument.

## Canonical command

```bash
scripts/rokid-research contract check --list
scripts/rokid-research contract check --track test21 --revision r3.3.4.2.6.1.2
```

## Equivalence definition

For each of the 29 Test 21 profiles:

1. the historical checker SHA-256 must match its locked profile identity;
2. the historical checker is executed directly against the repository;
3. the same locked checker is executed through the canonical contract framework;
4. return codes must match and be zero;
5. stdout must match exactly;
6. expected historical PASS markers must be present.

This stage therefore consolidates the **operator interface and lineage registry**, while leaving historical predicate implementations unchanged. Predicate-level deduplication is a later migration after the source-locked dispatch layer is qualified.

## Safety

`DEVICE_OPERATION=NONE`. The framework runs host-side repository source checks only. It does not launch device collectors or perform ADB, Frida, Magisk, Bluetooth, photo, audio, or network operations.
