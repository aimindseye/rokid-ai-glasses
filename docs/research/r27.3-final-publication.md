## Public/private boundary

The publication allowlist may contain reviewed Markdown and source files only. Private evidence ZIPs, raw packet captures, screenshots/media, APK/AAR/JAR/DEX artifacts, key material, generated build output, local absolute paths, credentials, device identifiers, and runtime evidence are excluded. Synthetic test literals are permitted only where explicitly allowlisted by the publication verifier.

## Git governance

The publication helper refuses unexpected pending paths, stages only the generated allowlist, runs the canonical consolidation/oracle/R27/link/privacy gates, creates a dedicated publication commit, and can optionally push a PR. Post-merge verification requires a clean `main` worktree and the same final machine gates before Test 22 starts.
