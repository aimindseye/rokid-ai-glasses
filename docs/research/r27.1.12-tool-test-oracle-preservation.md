# R27.1.12 — Tool-Test Oracle Preservation and R27.1 Retirement Finalization

## Purpose

R27.1.12 finalizes the Tests 19–21 `test_*_tools.py` family after the validator, evidence-packager, and Test 21 source-contract implementation families have converged on canonical engines.

The remaining tool tests are treated differently from those implementation families. Their value comes from being **independent regression oracles**: they compile synthetic Java fixtures, exercise ZIP/network behavior, emulate Frida-facing dependencies, inspect source-safety properties, and validate subprocess contracts. Replacing those tests with predicates implemented by the same canonical code they validate would weaken the regression boundary.

No repository path is deleted by this phase.

## Acceptance contract

A current tool-test oracle is accepted only when all of the following hold:

1. its exact SHA-256 matches the canonical tool-test registry;
2. it is invoked from the repository root with the current Python interpreter;
3. it completes successfully within its bounded timeout; and
4. its observed unittest count equals the registered historical count.

The canonical commands are:

```bash
scripts/rokid-research test verify-oracles
scripts/rokid-research test run --list
scripts/rokid-research test run --track test21 --revision r3.3.4.2.6.1.3
```

## Deferred fixture

`test21:r3.3.4.2.6.1.1` remains `DEFERRED_MISSING_FIXTURE` because `fixtures/synthetic-obfuscated-client-l-1.0.1.aar` is absent from the current repository. The historical test source remains source-locked and is preserved as historical lineage; R27.1.12 does not synthesize or silently replace the missing fixture.

## Provenance archive

The R27.1.12 verification output creates a deterministic private `tool-test-oracles.zip` containing all 39 registered historical tool-test files and a SHA-256 sidecar. The archive is evidence/provenance only; the live test files remain the execution oracles.

## Safety boundary

This phase performs host-only source-lock, unittest, fixture, documentation, and archive validation. It does not connect to a device, modify Bluetooth/Wi-Fi state, invoke privileged runtime instrumentation, or replay captured device payloads.

## Resulting R27.1 boundary

After acceptance, Tests 19–21/r25 no longer have an unresolved implementation-retirement queue. Further R27 work should return to the whole-history inventory and select the next host-only duplicated runner/analyzer/helper family rather than continuing to rewrite independent regression tests.
