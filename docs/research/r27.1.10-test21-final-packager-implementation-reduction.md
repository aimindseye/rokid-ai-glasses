# R27.1.10 — Final Test 21 Packager Implementation Reduction

## Purpose

Complete implementation consolidation for the Test 21 sanitized-evidence packaging family without deleting historical paths or weakening historical source/test/runner behavior.

R27.1.9 left sixteen packagers behind because source-contract, tool-test, or runner files still referenced their revision-specific paths. R27.1.10 preserves those implementations, replaces each active path with a CLI-compatible canonical shim, migrates the transitive source-contract SHA lineage, and classifies the remaining callers as compatibility callers.

## Compatibility boundary

Historical paths remain present and accept their historical CLI. Runners do not need an immediate rewrite because they now call a compatibility shim rather than a duplicated implementation.

Tool tests that intentionally inspect historical source markers continue to verify those compatibility-contract markers. The final `r3.3.4.2.6.1.3` packager also retains its `privacy_violation(...)` compatibility API while delegating privacy logic to the canonical privacy module.
