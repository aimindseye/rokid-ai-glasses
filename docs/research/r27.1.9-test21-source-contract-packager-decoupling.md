# R27.1.9 — Test 21 Source-Contract Packager Decoupling

## Purpose

Reduce revision-specific Test 21 packaging implementations that are blocked only by historical source-contract identity references, without weakening the source-contract chain or changing historical PASS behavior.

## Scope

Eleven packagers are migrated to canonical compatibility shims:

- `r1`
- `r2`
- `r3`
- `r3.3.1`
- `r3.3.2`
- `r3.3.3`
- `r3.3.3.1`
- `r3.3.3.2`
- `r3.3.3.2.1`
- `r3.3.4`
- `r3.3.4.1`

Their only non-canonical inbound dependency before this phase was the Test 21 source-contract lineage. Packagers that are still referenced by tool tests or runners are outside this phase.

## Preservation model

Before repository mutation, R27.1.9 SHA-256 verifies and archives:

- the eleven original packager implementations; and
- every source-contract checker whose prerequisite hash chain changes.

The archive is verified before any compatibility shim is installed.

## Contract migration

The source-contract checker chain uses exact predecessor identities. Replacing a packager therefore changes the accepted prerequisite identity for downstream revisions. R27.1.9 migrates this hash chain transitively and updates the canonical source-contract registry to the new checker identities.

Acceptance requires all 29 applicable Test 21 source-contract checks to return the same PASS stdout as immediately before migration.

## Packaging equivalence

Each of the eleven compatibility shims delegates to the canonical evidence packager using its revision profile. Synthetic safe evidence is packaged by both the preserved historical implementation and the shim, and ZIP member bytes plus sidecar validity must agree.

## Resulting retirement state

Expected cumulative state after PASS:

- compatibility shims: 26 total;
- remaining inbound-dependent Test 21 packagers: 16;
- output-container compatibility blockers: 0;
- source-lock failures: 0;
- repository path deletions: 0.

The remaining packagers require tool-test and/or runner dependency migration in a later phase.
