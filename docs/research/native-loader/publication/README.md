# Sanitized Additive Publication Artifacts

This directory contains the later startup-materialization, injection-trigger,
and evidence-transport publication layer. It is intentionally separate from:

- the top-level historical `loader-control-flow.mmd` native-runtime diagram;
- the historical `runtime-event-types.md` 102-event inventory;
- the historical `six-blocker-closure.md` native-runtime blocker table.

The files here describe a separate 647-event startup capture and the later
trigger/transport closure. They do not supersede those historical records.

Included:

- later loader/materialization and injection-trigger Mermaid diagram;
- later six-blocker CSV;
- 11 MyJni name/signature pairs with bounded startup counts;
- later callback and runtime-event counts;
- source hashes;
- injection-mode semantic comparison.

Excluded: raw proprietary binaries, raw events, absolute runtime addresses,
device paths, account data, and private evidence archives.
