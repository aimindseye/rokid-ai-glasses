## Publicly acceptable material

- sanitized Markdown findings;
- machine-readable summaries with sensitive fields removed;
- SHA-256 identities;
- diagrams reconstructed from validated facts;
- scripts that verify manifests or process already sanitized evidence;
- generic observation tooling written by the contributor.

## Keep private

- PCAP/PCAPNG and TLS keys;
- bugreports, raw logcat, and HCI logs;
- APKs, native libraries, firmware images, and decrypted payload dumps;
- serials, Bluetooth addresses, account IDs, tokens, and precise location;
- screenshots containing personal or proprietary information.

## Review rule

A public summary must remain reproducible from a separately retained private
evidence set, but the private set must never be required to build or validate
the public repository.
